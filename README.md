# new-agent- : la micro-entreprise d'agents

Une équipe d'agents IA qui travaillent ensemble comme une petite entreprise,
pour aider simo à réaliser beaucoup de tâches complexes.

## L'équipe

Voir [equipe/ORGANIGRAMME.md](equipe/ORGANIGRAMME.md).

## Comment l'utiliser

Il suffit d'écrire sa demande normalement à Claude dans le projet. Par exemple :

- « Directeur, crée-moi un agent qui gère mes réponses aux clients. »
- « Organise-moi la préparation de mon salon professionnel. »

## Où sont les choses

- `.claude/agents/` : une fiche par agent (son rôle, sa méthode, ses limites).
- `.claude/skills/creer-agent/` : la méthode que suit le directeur pour créer un agent.
- `equipe/ORGANIGRAMME.md` : la liste des agents et à quoi ils servent.
- `CLAUDE.md` : les règles communes à toute l'équipe.
