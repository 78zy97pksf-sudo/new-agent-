# Page de vente : ce qu'il reste à remplir

La page est dans `docs/index.html`. Les zones surlignées en jaune
`[ENTRE CROCHETS]` sont à remplacer par tes vraies informations :

- Ton nom ou ta marque, ton prénom, ta photo, 2 ou 3 phrases sur ton parcours
- Tes chiffres (nombre de clients, années d'expérience)
- Tes offres et tes prix (programme, suivi mensuel, formation)
- Tes liens de paiement (par exemple Stripe Payment Links, gratuit, une commission par vente)
- Le délai pour livrer un programme
- 3 témoignages de clients (avec leur accord)
- Ta politique si un client n'est pas satisfait
- Ton e-mail ou Instagram pour te contacter
- Ton SIRET, tes mentions légales et tes conditions de vente

## Mise en ligne (gratuite) avec GitHub Pages

Quand tout est rempli : sur GitHub, ouvrir le dépôt, aller dans
**Settings** > **Pages**, choisir la branche **main** et le dossier **/docs**,
puis **Save**. Le site sera visible à l'adresse
https://78zy97pksf-sudo.github.io/new-agent-/
