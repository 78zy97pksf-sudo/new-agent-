## Encore possible d'ajouter

## Mise en ligne (gratuite) avec GitHub Pages

Sur GitHub, ouvrir le dépôt, aller dans **Settings** > **Pages**, choisir la
branche **main** et le dossier **/docs**, puis **Save**. Le site sera visible à
l'adresse https://78zy97pksf-sudo.github.io/new-agent-/
