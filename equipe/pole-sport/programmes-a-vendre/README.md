# Programmes types à revendre

On range ici les **programmes types** : des programmes sans client précis,
que simo peut vendre (par exemple sur sa page de vente).

Un fichier par programme, par exemple :
`remise-en-forme-debutant-maison-8-semaines.md`.

## Règles

- Chaque programme est écrit par `coach-programmeur` avec l'en-tête
  « Programme type » de `../modele-programme.md` : public visé, niveau requis,
  à qui il ne convient pas, questionnaire santé à faire soi-même au début
  (avec renvoi vers le médecin en cas de « oui »).
- Il doit être **validé par `coach-securite`** (grille « programme type »)
  puis relu par `controleur-qualite` avant d'être mis en vente.
- En haut du fichier, noter l'état : « brouillon », « à faire valider » ou
  « validé le [date] ».
- Aucune donnée de vrai client ici.
