# Dossier des clients

## ATTENTION : le dépôt GitHub est PUBLIC

Tout le monde sur Internet peut lire ce qui est rangé ici.
**Tant que le dépôt est public, ne jamais y mettre de vraies données de
clients** : pas de nom complet, pas d'informations de santé, pas d'adresse,
pas de téléphone.

Deux solutions :
- utiliser **uniquement un code client** (ex. `client-012`) et des
  informations sans santé (exemples, tests) ;
- ou garder les vraies fiches **hors du dépôt** (sur ton ordinateur ou un
  dossier privé), ou rendre le dépôt privé.

## Organisation

Un dossier par client : `equipe/pole-sport/clients/<prenom-ou-code>/`
(de préférence un code, ex. `client-012/`).

Dans chaque dossier :
- `fiche-client.md` : le bilan fait par `coach-bilan` ;
- `programme.md` : le programme fait par `coach-programmeur` et validé par
  `coach-securite` ;
- `conseils-hygiene-de-vie.md` : seulement si des conseils de `coach-nutrition`
  ont été demandés.

On n'écrit que les informations **utiles** au programme.
